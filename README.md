# 📄 AI Resume Ranking System

An AI-powered Resume Ranking System that analyzes multiple resumes and ranks candidates based on Job Description matching.

## 🚀 Features

* ✅ Multiple Resume Upload (PDF)
* ✅ Resume Ranking
* ✅ ATS Score Analysis
* ✅ Job Description Matching
* ✅ Smart Weighted Scoring
* ✅ AI Resume Feedback using Groq API
* ✅ CSV Report Download
* ✅ Professional Streamlit UI

## 🛠️ Tech Stack

* **Python**
* **Streamlit**
* **Groq API (Llama 3.3)**
* **PDFPlumber**
* **Pandas**

## 📌 How It Works

1. Upload multiple resumes in PDF format
2. Paste Job Description
3. AI analyzes resumes
4. Candidates are ranked based on skill matching
5. AI feedback is generated for each resume

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/AnjleenaGupta/AI-Resume-Ranking-System.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
